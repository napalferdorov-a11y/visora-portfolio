# Videos

Put your `.mp4` files here:

- `showreel.mp4` — used by the Before/After colour-grade slider on the homepage.
- `film1.mp4` … `film6.mp4` — the video showcase grid (edit titles in `js/main.js`).
- `showreel-before.mp4` — *optional* raw/ungraded clip for a true A/B (see main README).

Use **H.264 MP4** for the widest browser support. Keep web clips short and
compressed (1080p, a few MB) so the page loads fast.
